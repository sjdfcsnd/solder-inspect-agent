## 一、完整板面演示

`演示_标注结果_board055.png`

测试板 board_055 的完整输出：24 个焊点按四行六列全部定位，红框为判定缺陷、绿框为正常，每个框上方标注类别与置信度，左上角为汇总（焊点 24、缺陷 10、待复核 0，占 0%）。

该板真值为 16 正常 + 2 桥连 + 2 少锡 + 2 多锡 + 2 偏移，模型判出 10 个缺陷且位置全部正确，其中两处桥连置信度 0.98 与 0.97，说明桥连判定的置信度分布与其它类别一致可信。

## 五、可运行原型

```
cd 代码
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

界面提供：照片上传、质量门控结果、四张指标卡（焊点数、判定缺陷、待复核、单图耗时）、标注图预览、逐点结果表（含处置与依据）、改判提交与完整 JSON 展开。改判写入 `results/review_log.jsonl`，可直接作为下一轮训练样本。
